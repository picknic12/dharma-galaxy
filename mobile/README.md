# 다르마 갤럭시 2027 · 안드로이드판

> 저자: 피크닉 신영호 · 임지혜 (이스턴드래곤 출판사)

PC판과 같은 게임 본체에 휴대폰용 조작·화면 배치를 얹은 판입니다. 이 저장소에는 PC판과 마찬가지로 **난독화된 배포본**(`docs/m/`)과 안드로이드 앱 껍데기(`mobile/android/`)만 있습니다.

## 받는 곳

| 형태 | 방법 |
|---|---|
| 설치형 웹앱(PWA) | 휴대폰 크롬에서 https://picknic12.github.io/dharma-galaxy/m/ → ⋮ → **홈 화면에 추가** |
| APK | 저장소 → Releases → `android-latest` → APK 내려받아 설치 |

## 휴대폰에서 달라지는 점

- 하단 탭바(🌌 우주 · 🚀 함대 · 🪐 자산 · 🛡 영웅 · ☰ 메뉴), 아래에서 올라오는 정보 시트
- 카메라 터치판(⟲ ⟳ ＋ － 🏠 🎯), 두 손가락 확대·축소
- 첫 탭에 소리 시작, 가벼운 그래픽(기본) / 고화질 전환
- 세로·가로 모두 지원, 안드로이드 뒤로 가기로 창 닫기
- 앱은 전체 화면 몰입 모드, 게임 중 화면 꺼짐 방지

## 빌드

GitHub에 올리면 **Actions → Android APK**가 `docs/m/`을 앱에 담아 APK를 만듭니다. `main`의 빌드는 `android-latest` 릴리스에 올라갑니다.
정식 서명 키가 없으면 시험용(debug) 서명 APK가 나옵니다. 정식 키는 GitHub Secrets(`DG_KEYSTORE_B64`, `DG_STORE_PASS`, `DG_KEY_ALIAS`, `DG_KEY_PASS`)로만 넣고 저장소에는 두지 않습니다.
Play 스토어 등록은 개발자 계정이 필요하므로 따로 진행합니다.
