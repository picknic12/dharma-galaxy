# 다르마 갤럭시 2027 · 안드로이드(모바일) 판

> 저자: 피크닉 신영호 · 임지혜 (이스턴드래곤 출판사)

PC판과 **같은 게임 본체**(`src/`, `lib/`, `vendor/`)를 쓰고, 그 위에 휴대폰용 조작·화면 배치만 얹은 판입니다.
게임 규칙을 고치면 PC판과 안드로이드판에 함께 반영됩니다. 모바일 폴더에는 규칙 코드를 두지 않습니다.

## 받는 곳

| 형태 | 주소 · 방법 |
|---|---|
| 설치형 웹앱(PWA) | 휴대폰 크롬에서 https://picknic12.github.io/dharma-galaxy/m/ → 메뉴 ⋮ → **홈 화면에 추가** |
| APK | GitHub 저장소 → Releases → `android-latest` → `DharmaGalaxy2027-*.apk` 내려받아 설치 |

## 휴대폰에서 달라지는 점

- **하단 탭바**: 🌌 우주 · 🚀 함대 · 🪐 자산 · 🛡 영웅 · ☰ 메뉴 (PC의 오른쪽 패널은 아래에서 올라오는 시트로)
- **☰ 메뉴**: 음악·명상·수동/자동·속도·AI 오토·효과음·규칙·저장·불러오기·새 게임 + 그래픽 모드·이름표
- **카메라 터치판**: ⟲ ⟳ 회전, ＋ － 확대·축소, 🏠 내 우주, 🎯 따라가기 · **두 손가락 벌리기/오므리기**로 확대
- **탭으로 소리 시작**: 첫 터치에서 우주 음악과 효과음이 켜집니다
- **가벼운 그래픽**(기본): 해상도·별 수를 줄이고 초당 30장으로 그려 배터리와 발열을 아낍니다. ☰ 메뉴에서 고화질로 바꿀 수 있습니다
- **세로·가로 모두 지원**, 안드로이드 **뒤로 가기** 버튼으로 창 닫기, 두 번 누르면 종료
- 앱(APK)은 전체 화면 몰입 모드이며 게임 중 화면이 꺼지지 않습니다

## 만들기

```bash
python3 build.py                 # PC판 docs/index.html + 모바일판 docs/m/ 동시 생성
cd mobile && npm ci && npm run sync && (cd android && ./gradlew assembleDebug)   # 안드로이드 SDK가 있는 PC에서 APK 생성
```

GitHub에 올리면 **Actions → Android APK**가 자동으로 APK를 만듭니다. `main`에 들어간 빌드는 `android-latest` 릴리스로 올라갑니다.

## 서명 키

- 정식 키가 없을 때 APK는 **시험용(debug) 서명**으로 만들어집니다(파일 이름 끝 `-test`). 설치·시험에는 문제가 없지만, 빌드마다 키가 달라 새 버전을 설치할 때 이전 앱을 지우고 깔아야 할 수 있습니다(저장 데이터도 지워짐).
- 정식 키를 만들어 GitHub Secrets(`DG_KEYSTORE_B64`, `DG_STORE_PASS`, `DG_KEY_ALIAS`, `DG_KEY_PASS`)에 넣으면 그 키로 서명된 release APK가 나오고, 덮어 설치가 됩니다. 키 파일과 비밀번호는 저장소에 넣지 않습니다.
- Play 스토어 등록은 개발자 계정이 필요하므로 따로 진행합니다.
